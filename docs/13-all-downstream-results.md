# 冻结 Qwen 小样本：34 项下游任务结果

这是流程验证和探索性对照，不是论文的全量复现或可用的临床预测模型。
任务和标签来自作者代码；使用冻结的 Qwen 基座和已训练预测器，患者按原划分抽样，训练/验证/测试患者互不重叠。
前三个对照分别为：历史信息 32 维、历史信息 64 维、历史信息 32 维加预测未来状态 32 维；分类器为逻辑回归，PCA 和标准化只在训练集拟合，超参数由验证集选择。
预测未来时，24 小时之后假设无干预，未使用真实未来检查或治疗；这是可能不符合临床实际的人工假设，不是治疗建议或已验证的因果反事实。
每项指标为测试集 AUROC / AUPRC；后者是 average precision。置信区间按患者重采样 500 次。
住院级任务在本表使用 48 小时预测特征；先前单独死亡率实验使用 24 小时，因此加预测状态的分数可略有不同。
